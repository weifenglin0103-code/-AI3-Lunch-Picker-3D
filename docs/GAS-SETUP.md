# 結帳系統 × Google Sheet（Apps Script）設定指南

## 架構

```
顧客瀏覽器 (index.html)
   │  POST JSON（Content-Type: text/plain，避免 CORS 預檢）
   ▼
Google Apps Script 網頁應用程式 (gas/Code.gs)
   ├─ 驗證欄位、以「菜單」工作表重新計價（不信任前端價格）
   ├─ 依訂單編號去重（斷線重送不會重複）
   ├─ 寫入「訂單」「訂單明細」
   └─ 寄信：店家新訂單通知、顧客確認信（有填 Email 時）
Google Sheet：菜單 / 訂單 / 訂單明細
```

斷線時前端會把訂單暫存在 localStorage，恢復連線後自動重送（訂單編號相同，伺服器會去重）。

## 設定步驟（約 10 分鐘）

1. **建立試算表**：到 Google 試算表新增一份空白檔案，命名例如「煎記訂單」。
2. **開啟 Apps Script**：選單「擴充功能 → Apps Script」。
3. **貼上程式**：
   - 把 `gas/Code.gs` 的內容整份貼進 `Code.gs`。
   - 專案設定 → 勾選「在編輯器中顯示 appsscript.json 資訊清單檔案」，把 `gas/appsscript.json` 內容貼進去。
4. **設定店家信箱**（可選）：`CONFIG.OWNER_EMAIL` 填入通知信箱；留空則寄給試算表擁有者。
5. **執行初始化**：函式選單選 `setup` → 執行，依畫面授權。會建立三張工作表、狀態下拉選單與預設菜單。
6. **部署**：右上「部署 → 新增部署作業 → 類型：網頁應用程式」
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 部署後複製以 `/exec` 結尾的網址。
7. **接上網站**：把網址貼到 `index.html` 的 `const GAS_ENDPOINT = '';`，commit 並部署。
8. **測試**：網站下一筆測試訂單，確認「訂單」「訂單明細」工作表出現資料，信箱收到通知。
9. **每日彙整**（可選）：重新整理試算表，選單「煎記工具 → 安裝每日營收彙整（21:30）」。

> 之後若修改 `Code.gs`，要「部署 → 管理部署作業 → 編輯 → 新版本」，網址才會套用新程式。

## 日常營運

| 想做的事 | 作法 |
|---|---|
| 暫停某品項 | 「菜單」工作表把該列「上架」取消勾選，之後的訂單會被拒絕並提示「暫停供應」 |
| 調整價格 | 直接改「菜單」工作表的單價（以此為準，前端顯示價格另需同步改 `index.html`） |
| 追蹤出餐進度 | 「訂單」工作表「狀態」欄用下拉選單切換（新訂單／製作中／可取餐／已完成／已取消），自動上色 |
| 查營收 | 「訂單明細」可直接用樞紐分析表；或使用每日彙整信 |

## 注意事項

- 價格以伺服器為準：前端傳來的 `clientTotal` 只供參考，回傳的 `total` 才是實際金額。
- 運費規則（NT$160、滿 NT$1,500 免運）在 `Code.gs` 的 `CONFIG` 與 `index.html` 各有一份，要改請兩邊同步。
- 公開的網址任何人都能送單。已做的防護：欄位驗證、數量上限、蜜罐欄位、公式注入處理、LockService 防競態。若遭惡意灌單，可再加 reCAPTCHA 或每支手機每分鐘限制次數。
- 每日寄信與 MailApp 有配額（一般 Gmail 約 100 封/日、Workspace 約 1,500 封/日）。
- 試算表內含顧客個資（姓名、電話、地址），請限制分享對象。
